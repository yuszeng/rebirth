# Rebirth — 游戏设计定案

> 实现前先读本文与 `ARCHITECTURE.md`、`ROADMAP.md`。  
> 玩法定案以本文为准；未实现的系统只描述边界，不要求现在写代码。  
> **进度：** Phase 1–4 已完成；下一阶段是 Phase 5（装备），需明确指令后再做。

## 核心定位

这是一款「剑与魔法 + Roguelike + 转生 + 世界事件」的动作游戏。

战斗体验参考 Brotato 一类自动战斗 Roguelike：

- 玩家主要控制**移动和走位**
- 普通攻击、技能、魔法、队友均为**自动执行**
- 玩家通过 **Build** 决定战斗方式

与传统 Roguelike 的核心区别：

> 每一次死亡都是一次人生结束。  
> 下一次游戏是新的转生。  
> 玩家是同一个灵魂，但每一世的选择会影响之后的世界。

## 玩家控制原则

- **不要**设计 QWER 技能栏。
- 玩家不主动按攻击键。
- 只有一个玩家实体 `Player`，不按职业拆成 Swordman / Mage / Assassin。
- 职业感来自武器、装备、技能、宝物构筑，而不是角色类。

## 长期游戏循环

```
转生 → 选择加护 → 进入冒险 → 战斗回合 → 经验/金币
→ 属性升级 → 商店 → 离开商店 → 奇遇 → 世界状态变化
→ 下一回合 → 魔王事件 → 继续冒险 → 死亡
→ 本世结算 → 跨转生数据更新 → 下一次转生
```

当前不实现完整循环。已实现到 **Phase 4**：战斗回合 → 升级补选 → 商店（属性或技能）→ 下一回合；按 E 在普通攻击和已购技能之间切换当前攻击方式。死亡则本世结算。  
战斗系统必须与剧情/转生解耦，以便未来无限模式复用战斗。

## 本世 vs 跨转生

必须始终区分：

| RunState（这一世） | PersistentState（跨转生） |
| --- | --- |
| HP、等级、技能、装备 | 羁绊、剧情进度 |
| 金币、队友、地图进度 | 解锁、世界状态、转生次数 |

死亡时：结束 `RunState` → 产出 `RunResult` → 更新 `PersistentState` → 创建新的 `RunState`。

## 攻击方式（Phase 4）

当前：普通武器攻击自动执行；已购技能可按 E 切换为当前攻击方式，并按冷却自动执行。  
未做：条件触发、命中/击杀/受伤触发、被动技能、魔法管道、QWER。

## 目标选择（未来能力）

最近、最低/最高 HP、Boss 优先、最近精英、随机、扇形、范围、背后、多目标。  
Phase 1：攻击范围内最近敌人。

## 内容体系（未来，数据驱动）

- 剑术 / 魔法 / 技能 / 装备 / 宝物 / 队友
- 羁绊 / 奇遇 / 世界状态 / 魔王 / 转生 / 主线 / 无限模式

技能新增应主要靠新的数据资源，而不是改核心 if/else。  
熟练度影响出现权重，但**不得锁死**高阶技能（保留极低概率 Jackpot）。

技能升级可以改变行为，并允许进化分支，而不是只做 `Damage +10%`。

## 商店（Phase 3–4）

当前：随机货架，购买 / 刷新 / 价格 / 加权随机。商店不解析效果，只提供货架。  
购买后由 `GameManager` 分支：无 `Skill` 的商品转成 `StatModifier`；有 `Skill` 的交给 `SkillController`。同一技能不可重复购买。  
未来货架还可换成 Treasure / Equipment / Companion，不必改商店流程。

## 魔王（未来）

不是固定最终 Boss 角色，而是 `DemonKingSystem + DemonKingState + HostCharacter`。  
可能换宿主、逃走变强、被他人击败后重新出现。

## 奇遇（未来）

战斗回合后：商店 → 奇遇。  
奇遇改 WorldState / Companion / DemonKing / 奖励 / 后续事件。  
必须数据驱动，不写死在 GameManager。

## 当前 Phase 1 体验（已定案的最小可玩）

- 中立占位角色：移动、HP、死亡
- 一把剑：自动攻击、范围、攻速、基础伤害
- 一种近战敌人：追踪、接触伤害、HP、死亡
- 持续刷怪；击杀掉 XP 与金币
- XP 满：暂停并出现 3 个动态生成的属性选项（攻/攻速/移速）
- HP=0：结算存活时间、击杀、等级、金币，可重新开始

Phase 1 **不做**：魔法、技能、装备、宝物、商店、队友、羁绊、奇遇、转生、魔王、剧情、无限模式、正式美术。

## 当前 Phase 3 体验（已完成）

- 每回合战斗时长由 `CombatLoopConfig` 配置（代码默认 60 秒；现用 `content/run/combat_loop.tres`）
- 时间到：清场 → 本回合攒下的升级一次选完 → 商店
- 战斗中升级只涨等级与经验，不打断战斗
- 4 个随机商品，可用本局金币购买；可花金币刷新；可空手离开
- 商品可以是属性修饰，也可以是技能（Phase 4）
- 离开商店后开始下一回合：等级、金币、已购加成与技能保留；玩家移回场地中心并回满 HP
- 玩家死亡仍立即结算，不进商店
- ESC 可暂停战斗（升级/商店/结算界面不抢占）

## 当前 Phase 4 体验（已完成）

- 商店可买「旋风斩」（自身圆伤）和「点射」（最近敌人）
- 按 E 在普通攻击和已购技能之间切换当前攻击方式；当前技能没目标则短间隔再试，不锁死整段 CD
- HUD 显示技能剩余冷却；无技能时战斗与 Phase 3 相同
- 不做：主动按键、法力、命中/击杀触发、技能进化

未开始：装备、魔法、宝物、队友、奇遇、转生、魔王、剧情、无限模式。
