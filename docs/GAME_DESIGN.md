# Rebirth — 游戏设计定案

> 实现前先读本文与 `ARCHITECTURE.md`、`ROADMAP.md`。  
> 玩法定案以本文为准；未实现的系统只描述边界，不要求现在写代码。  
> **进度：** Phase 1–4 已完成（旧：俯视自动战斗 + 计时回合）；Phase 5a（装备栏 + 背包）进行中。  
> **玩法转向已定案、尚未改代码：** 2D 3/4 房间战（类哈迪斯操作与构图，**不做 3D**）。房间/手动攻击/新相机未接到指令前不要开工。Phase 6+ 需明确指令后再做。

## 核心定位

这是一款「剑与魔法 + Roguelike + 转生 + 世界事件」的**动作肉鸽**。

战斗体验参考哈迪斯一类**房间战**：

- 画面是 **2D 3/4（四分之三侧视）**，房间像一座小舞台，不是正上方俯视的幸存者圈地
- 玩家控制**移动、面向、普攻、冲刺**
- 技能/魔法后续接到按键，不作为自动扫场
- Build（武器、装备、技能、宝物）决定「按下时发生什么」，而不是代替操作

引擎与空间：**Godot 2D 物理（XY 地面）+ 3/4 表现**。禁止为「更像哈迪斯」改成 Godot 3D / `CharacterBody3D`。

与传统 Roguelike 的核心区别：

> 每一次死亡都是一次人生结束。  
> 下一次游戏是新的转生。  
> 玩家是同一个灵魂，但每一世的选择会影响之后的世界。

房间结构是为了让奇遇、NPC、魔王、转生 Hub 能挂在「下一扇门」上，而不是插进无限刷怪圈。

## 画面与相机（已定案）

| 项 | 定案 |
| --- | --- |
| 渲染 | 继续 2D（`Node2D` / `CharacterBody2D`），不做 3D 场景或透视网格角色 |
| 构图 | 3/4：能看见身体与面向，不是头顶圆点；占位可用人形/胶囊 + 朝向 |
| 深度 | 用 Y 排序（脚的 Y 决定遮挡），柱子、门、角色互相挡住 |
| 相机 | **房间锁定**：整间入画，仅在靠近边缘时轻微推动；不要高空跟随式幸存者相机 |
| 移动 | WASD：上 = 往房间深处（屏幕上方）；攻击默认朝**面向**（最后非零移动方向） |

第一份可玩表现：一间有墙、出生点、出口门的样板房。无边大竞技场不再作为目标体验。

## 玩家控制原则

- 只有一个玩家实体 `Player`，不按职业拆成 Swordman / Mage / Assassin。
- 职业感来自武器、装备、技能、宝物构筑，而不是角色类。
- **最小动作集（转向后）：** 移动、面向、轻击（当前武器）、冲刺（短暂无敌）。
- 不要一上来做满哈迪斯的 Attack / Special / Cast / Call，也不要做 QWER 六技能栏。
- 后续技能：最多先接 **1 个副攻击/投技槽**，冷却触发，走现有 `AttackPattern` 数据，禁止自动释放当主循环。
- 近战判定优先「朝前扇形 / 武器形状」，玩家普攻不以「自动锁最近敌人」为唯一朝向。

## 长期游戏循环

```
转生 → 选择加护 → 进入冒险 → 战斗房（清场开门）
→ 选择下一扇门 → 商店房 / 事件房 / 再一间战斗房
→ 经验/金币/构筑 → 魔王房或世界事件 → 死亡
→ 本世结算 → 跨转生数据更新 → 下一次转生
```

当前不实现完整循环。代码仍是 **Phase 4 + 5a**：计时战斗回合 → 升级补选 → 商店 → 下一回合；商店页可看装备栏与背包；按 E 切换已拥有武器。死亡则本世结算。

战斗必须与剧情/转生解耦：无剧情时只跑战斗房仍可打完一局；无限模式复用 Combat + Content。

## 本世 vs 跨转生

必须始终区分：

| RunState（这一世） | PersistentState（跨转生） |
| --- | --- |
| HP、等级、技能、装备 | 羁绊、剧情进度 |
| 金币、队友、房间进度 | 解锁、世界状态、转生次数 |

死亡时：结束 `RunState` → 产出 `RunResult` → 更新 `PersistentState` → 创建新的 `RunState`。

## 房间（已定案，待实现）

房间类型先三种：

- **战斗房：** 进门锁门 → 按波次刷怪 → 清场开门
- **商店房：** 复用现有商店流程（可以是独立房间或清场后 UI，实现时再选）
- **事件房：** 占位即可（先奖励/离开）；正式奇遇走后续 Phase，不写死在 `GameManager`

第一版房间流：线性 4～6 房 + 末房，不要先做完整分支地图。  
刷怪入口仍是 `SpawnDirector`，改为「本房波次」，不要另写一套生成器。  
**不再以 60 秒计时作为进店条件**（`CombatLoopConfig` 回合计时是旧循环，房间 Phase 开工后替换）。

不要并行维护「圈地生存」和「房间战」两套主循环。

## 攻击与技能

**已交付（Phase 4，旧控制）：** 开局选武器，商店买武器，按 E 切换，`AttackController` / `SkillController` 冷却到了自动打最近目标。

**转向后（待对应 Phase）：**

- 普攻 = 当前 `WeaponData` 的 `AttackPattern`，按键 + 冷却
- `SkillData` 留下，改成按键释放；关掉自动循环
- 仍禁止用技能/武器 Id 字符串分支攻击逻辑
- 未做：命中/击杀/受伤触发、被动技能、魔法管道、技能进化、满键位技能栏

## 目标选择（未来能力）

最近、最低/最高 HP、Boss 优先、最近精英、随机、扇形、范围、背后、多目标。  
玩家普攻以面向与形状为主；「最近敌人」仍可用于部分追踪弹、敌人 AI、辅助索敌，不是唯一策略。  
Phase 1 旧实现：攻击范围内最近敌人。

## 内容体系（未来，数据驱动）

- 剑术 / 魔法 / 技能 / 装备 / 宝物 / 队友
- 羁绊 / 奇遇 / 世界状态 / 魔王 / 转生 / 主线 / 无限模式

技能新增应主要靠新的数据资源，而不是改核心 if/else。  
熟练度影响出现权重，但**不得锁死**高阶技能（保留极低概率 Jackpot）。

技能升级可以改变行为，并允许进化分支，而不是只做 `Damage +10%`。

## 商店（Phase 3–5a）

当前：随机货架，购买 / 刷新 / 价格 / 加权随机。商店不解析效果，只提供货架。  
购买后由 `GameManager` 分支：有 `Weapon` 的加入武器列表与背包；有 `Equipment` 的加入护甲背包并可穿上；否则转成 `StatModifier`（不进背包）。已拥有的武器与护甲不再上架。  
商店页同时展示六格装备栏与背包（查看已购武器/护甲，点击背包可换装）。  
未来货架还可换成 Treasure / Companion，不必改商店流程。房间化后商店作为「商店房」挂上同一套服务即可。

## 魔王（未来）

不是固定最终 Boss 角色，而是 `DemonKingSystem + DemonKingState + HostCharacter`。  
可能换宿主、逃走变强、被他人击败后重新出现。适合作为 Boss 房 / 世界旗标，而不是下一波小怪。

## 奇遇（未来）

挂在事件房或门后选择上，而不是「每一波计时结束后固定插入」。  
奇遇改 WorldState / Companion / DemonKing / 奖励 / 后续事件。  
必须数据驱动，不写死在 GameManager。

## 已交付：Phase 1 体验（旧循环，历史）

- 中立占位角色：移动、HP、死亡
- 一把剑：自动攻击、范围、攻速、基础伤害
- 一种近战敌人：追踪、接触伤害、HP、死亡
- 持续刷怪；击杀掉 XP 与金币
- XP 满：暂停并出现 3 个动态生成的属性选项（攻/攻速/移速）
- HP=0：结算存活时间、击杀、等级、金币，可重新开始

Phase 1 **当时不做**：魔法、技能、装备、宝物、商店、队友、羁绊、奇遇、转生、魔王、剧情、无限模式、正式美术。

## 已交付：Phase 3 体验（旧循环）

- 每回合战斗时长由 `CombatLoopConfig` 配置（代码默认 60 秒；现用 `content/run/combat_loop.tres`）
- 时间到：清场 → 本回合攒下的升级一次选完 → 商店
- 战斗中升级只涨等级与经验，不打断战斗
- 4 个随机商品，可用本局金币购买；可花金币刷新；可空手离开
- 商品可以是属性修饰、尚未拥有的武器，或尚未拥有的护甲
- 离开商店后开始下一回合：等级、金币、已购加成与已拥有武器保留；玩家移回场地中心并回满 HP
- 玩家死亡仍立即结算，不进商店
- ESC 可暂停战斗（升级/商店/结算界面不抢占）

## 已交付：Phase 4 体验（旧控制）

- 开局动态选择一把初始武器；铁剑、飞刃及贯穿、散射、连锁、光束、延迟爆炸、环绕刀阵均为 `WeaponData`
- 商店可买尚未拥有的武器；开局已选和已购武器不会再出现
- 按 E 在本局已拥有武器之间切换当前攻击方式
- 当时不做：主动按键、法力、命中/击杀触发、技能进化

## 当前 Phase 5a 体验（进行中）

- 装备栏六槽：头部、手部、胸部、裤子、鞋子、武器
- 护甲改属性与占位外观层；无护甲时仍是中立圆点（3/4 人形外观属于后续视角 Phase，不在 5a 范围）
- 武器槽 = 当前攻击用的 `WeaponData`；开局武器算已拥有，出现在背包里
- 商店可买护甲；已购武器与护甲进本局背包，可在商店页查看与换装
- 属性商品仍是一次性加成，不进背包

未开始：3/4 样板房、房间相机、手动普攻/冲刺、房间流、按键技能、魔法、宝物、队友、奇遇、转生、魔王、剧情、无限模式。
